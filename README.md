# Gabel

Gabel es una aplicación móvil creada para facilitar el control y seguimiento de las principales áreas de un salón de belleza.

Esta versión móvil está enfocada principalmente en brindar acceso rápido a la información del negocio, permitiendo consultar y gestionar el inventario, productos, servicios, usuarios, roles. Catálogos necesarios para su administración.

La aplicación también permitirá consultar los historiales de compra y venta, facilitando el seguimiento de las operaciones que se han realizado en el negocio. Además, contará con un dashboard y reportes para visualizar información relevante y tener una mejor perspectiva del funcionamiento del salón.

A diferencia del sistema web, la aplicación móvil no estará orientada a realizar procesos transaccionales, por lo que no se podrán registrar nuevas compras o ventas desde ella. Su propósito será funcionar como una herramienta de apoyo para la consulta, supervisión y gestión de Gaby Salon desde un dispositivo móvil.
